# Kesiya Saji - Developer Portfolio

🌐 **Live Website:** [https://precious-alfajores-f6ff68.netlify.app/](https://precious-alfajores-f6ff68.netlify.app/)

A modern, responsive personal portfolio web application built with **React, Vite, Tailwind CSS, Framer Motion**, and a **Django** backend REST API.

---

## 🚀 Features

- **Dynamic Hero & About Section:** Sleek dark-mode aesthetic with smooth animations.
- **Projects Showcase:** Highlights personal and team projects with live demos and source code links.
- **Certifications & Document Viewer:** Preview PDF certificates directly in-app.
- **Skills & Education Timeline:** Clean visual breakdown of technical competencies and academic history.
- **Backend API Integration:** Django REST Framework API for managing resumes and certificates dynamically.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite, Tailwind CSS, Framer Motion, Lucide React Icons
- **Backend:** Django, Django REST Framework, SQLite
- **Deployment:** Netlify

---

## 💻 Local Setup & Development

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
python manage.py runserver
```
